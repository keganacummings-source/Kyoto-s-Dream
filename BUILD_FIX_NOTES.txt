KYOTRIPPAH BUILD FIX — 2026-10-05

- Windows and macOS both failed in Source/PluginEditor.cpp.

2. Added propertyOr(...) helper for DynamicObject properties with fallbacks.
3. Replaced all CI-reported DynamicObject getProperty(name, default) calls with propertyOr(...).
4. Left ValueTree getProperty usage unchanged where its API is valid.
5. Re-scanned PluginEditor.cpp for the reported two-argument DynamicObject calls; none remain.

The supplied CI log showed no additional C++ errors after these failures; the job exited because PluginEditor.cpp did not compile.

KYOTOSPXRIT — Builder & Playground Guide

Right-click the playground → Guide opens this help. Esc or × closes it.

1. Big picture

The Plugin Builder is a visual modular workshop. You place plastic parts on a shell template (the machine body). Only effects you place and wire change the sound. Skins, vents, badges, and body cosmetics are visual only.

Signal path: Input → wired effect stages (in wire order) → output. Screens / WAV modules are visual taps — they show the signal; they do not process audio by themselves.

2. Quick start walkthrough

Step 1 — Motherboard On a blank playground, right-click → Place Motherboard. This is the board/screen of your machine.
Step 2 — Template and theme Right-click → Template picks bay layout (knobs, faders, keys). Theme paints shells, chat, and chrome.
Step 3 — Place an effect Right-click → Add → pick a family (Delay, Reverb, …) → choose an effect. It snaps into a free knob/fader bay.
Step 4 — Wire (manual) Left-click the source part to select it. Right-click the target part → Put wire Into. Signal runs destination first, then the source.
Step 5 — Bind a dial Arm a dial, then click an occupied effect bay. Choose Mix %, Decay, Time, Hz, Strength, etc. A satellite dial drives that parameter.
Step 6 — Hear and show Right-click → Plugin View for a live faceplate. Geek reveals internals and the signal path.
Step 7 — Save / Publish Save Build stores locally. Publish needs DreamShare sign-in.

3. Systems by importance

A. Placement and bays (core)

  • Shell / Template — Fixed bay map (knob, fader, key, screen, cosmetic). Parts must fit the bay type.
  • PLACE / right-click Add — Arms a part, then click a glowing bay (or Add auto-picks nearest free bay).
  • No auto-wire on place — New parts start unwired on the motherboard. Connect with Put wire Into.
  • Resize grips — Select a part; drag corners/edges. Larger bays get richer plastic detail.

B. Wiring (core)

  • Put wire Into — Selected part plugs into the right-clicked part. DSP order updates (wireOrder).
  • Clear wire — Removes the link from the selected part.
  • Order rule — Destination processes first, then the wired source. Screens store tapAfter so later effects are not implied on earlier screens.
Wires are intentional. Placing parts no longer chains automatically from the selection.

C. Effect controls (core)

  • Each effect stage has: On, Type, Amount, Tone, Motion, Mix, Shape.
  • Dial-on-effect binds a physical dial to one of those (or family aliases: Decay→Amount, Time→Motion, Hz→Tone).
  • FX EDIT (right-click selection) opens numeric editors for the same parameters.
  • Chain Break / Master Mix — Split parallel chains or set overall wet balance.
  • Per-chain levels — Optional volume per chain after Breaks.

D. Plugin View and Geek (important)

  • Plugin View — Full-screen live machine; only Back + Geek.
  • Geek — X-ray internals, signal path, stage badges, satellite dial markers, screen TAP labels. Low CPU when closed.

E. Cosmetics and modular pieces (secondary)

  • Skins (copper, mint, violet, …) recolour plastic; they do not change DSP.
  • Modular pieces (Snap Dial, Lens Knob, …) are cosmetic look + quirk label.
  • Vents, rails, badges fill cosmetic bays only.

F. DreamShare social (separate tab)

  • Chat / Discord rail, threads, catalog of published plugins. Themes style this chrome as well as the builder.

6. Themes and plastic look

  • Right-click Theme applies playground shell colours and DreamShare UI together.
  • Parts are cartoonish plastic: shell, gloss, accent rim. Resize tiers shift palette (tiny = muted, large = more accent).
  • Dial silhouettes vary (pointer, arc, dual ring, flat, gem) from part identity — still theme-coloured.

7. Save, randomize, undo

  • Randomize Template — rolls parts into the current shell (essentials first).
  • Randomize Machine — body / aspect playground cosmetics.
  • Undo — restores last builder snapshot.
  • Save Build / Publish — local file vs DreamShare upload.

8. Common pitfalls

  • Effect silent? Check stage On, Mix amount, and that a wire path reaches the output.
  • Cannot place a part? Bay type mismatch or bay full — try another template or Swap Part.
  • Dial will not bind? Click an effect host bay (not empty cosmetic).
  • Closing the UI in FL: timers shut down cleanly — reopen the editor from the mixer.

# 0.5.4 Manual wire + themes + FX uniqueness

## Wiring (manual only)
1. **Left-click** a part to select it (source).
2. **Right-click** another part → **Put wire Into: target ← source**.
3. Signal order: destination processes first, then the wired source.
4. **Clear wire from selected** removes the link.
5. Placing new parts no longer auto-chains into the selection.

## Themes
- DreamShare theme (`themeBox` / applyTheme) colors chat, text fields, combos, scrollbars, SocialRail, ThreadBoard, popup menus.
- Builder right-click **Theme** applies both playground (shells/widgets) and DreamShare UI theme.
- Shells and Plugin View follow playground theme accents.

## FX
- Each of the 200 slots gets a stronger per-index fingerprint (rate, profile, amount scale) so related Kind recipes still sound distinct.

## Pairing modules
- Effect + dial-on-effect bind (Mix / Decay / Hz / …) still works.
- Manual wires let you route any processing stage into any other for custom chains.
